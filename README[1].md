# معمار الوحي | منصة الثقافة الإسلامية المعاصرة

«على بصيرة العقل وهداية الوحي — نحيا كراماً»

منصة عربية (RTL) تنظّم المحتوى المعرفي في 6 بوابات و20 محوراً، ولكل محور: كتب ومراجع، مقالات وأبحاث، مرئيات ودروس.

## المزايا
- تصميم داكن بخطوط عربية (Amiri, Reem Kufi, Scheherazade New)
- بحث فوري في المحاور
- تصميم متجاوب مع الجوال

## الملفات
- `index.html` الصفحة الرئيسية
- `style.css` التنسيق
- `logo.jpeg` الشعار

## التشغيل
افتح `index.html` في المتصفح، أو انشره عبر GitHub Pages.

## الإشراف
تحت إشراف الأستاذ الباحث: رماضنة عبد العزيز
